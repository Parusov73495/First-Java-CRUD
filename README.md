# First Java CRUD

This is my Java project for managing students. I created it using Spring Boot.

## About the project

The application is used to manage student information, such as names and email addresses.

## Technologies

- Java 21
- Spring Boot
- Maven
- Thymeleaf
- HTML

## How to run

1. Open the project in IntelliJ IDEA.
2. Make sure Java 21 is installed.
3. Run `FirstJavaCrudApplication.java`.
4. Open http://localhost:8080 in your browser.

## Project structure

- `src/main/java` — Java code
- `src/main/resources/templates` — HTML pages
- `src/main/resources/application.properties` — application settings
- `pom.xml` — Maven dependencies and project configuration
